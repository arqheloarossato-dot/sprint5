Projeto Sprint 5

Aplicação web desenvolvida com Streamlit para análise exploratória de dados de anúncios de veículos usados.

Funcionalidades
Exibição de histograma da quilometragem dos veículos.
Exibição de gráfico de dispersão entre preço e quilometragem.
Visualizações interativas utilizando Plotly Express.
Tecnologias utilizadas
Python
Pandas
Plotly Express
Streamlit
